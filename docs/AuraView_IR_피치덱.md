## 한 줄 요약 (Elevator Pitch)

스마트기기 한 대로 **25종 공공데이터를 실시간 융합**하고 **차량 간 협력 인지(V2V)** 를 결합해,
운전자가 못 본 사각지대 위험을 **평균 3.38초 먼저** 알리는 한국 도로 특화 AI 플랫폼.
그 과정에서 모인 **익명 사각지대 데이터가 지자체 정책의 근거**가 되는 데이터 플라이휠을 만든다.

**핵심 지표** — 선행경고 3.38초 (일반 ADAS 0.5초) · 회피 성공률 25% → 84.5% · 자체 학습 AI 정확도(AUC) 0.9403 · 11개 기관 25종 데이터 융합

## 1. 문제 (Problem)

### 한국 도로 사망의 22%는 '보였다면 피했을' 사고
- TAAS 2024: 연간 사망 **2,581명**, 부상 **290,400명**
- 도시 교차로 사고 비중 **46%**, 그 중 트럭·버스에 **시야가 가려 일어난 사고 22%**
- 고령(65세 이상) 사망 비중 **46%**

### 왜 못 막나 — 두 개의 빈틈
1. **가려진 위험을 사전에 못 본다.** 단일 카메라 ADAS·글로벌 FSD는 트럭 뒤 신호, 좌측 사각 이륜차 등을 사전 인지 불가. 선행경고 0.5초, 회피율 25% 미만.
2. **사각지대 사고가 데이터로 남지 않는다.** 매일 쏟아지는 위험이 '어디가·왜 위험한지' 통계로 축적되지 않음 → 정책도 설문·사후 통계에 의존.

> 글로벌 FSD(Tesla 등)도 한국형 8대 위험 시나리오(트럭·신호 가림, 우회전 보행자, 스쿨존…)와 한국 법령 체계를 학습하지 않았다.

| **법** | 민식이법 · 우회전 보행자 일시정지(2022) | 운전자 형사 책임 강화 → **객관적 회피 데이터 수요** 발생 |

| **시장** | 블랙박스 **1,500만 대** 보급 | 카메라 거치 습관·하드웨어가 이미 전국에 — **새 기기 설득 없이 진입** |

## 3. 해결 방식 (Solution)

**"차 한 대의 눈으로는 부족하다 — 도로 전체를 하나의 센서로."**

```
[ 단말 ]  카메라 1대(스마트기기/블랙박스) + 온디바이스 AI 객체 인식
   +
[ 서버 ]  25종 공공데이터를 0.2초 안에 융합 → 사각지대 위험 '계산'
   +
[ 차량간 ] V2V 협력 인지 — 반경 200m 차량이 위험을 동시에 공유
   ↓
운전자가 못 본 위험을 평균 3.38초 먼저 · 회피율 84.5%
   ↓
막는 동시에, 그 사각지대를 익명 통계로 축적 → 정책 환원
```

특수 장비 0원. 폰 한 대를 거치하면 된다.

## 4. 제품 (Product)

### 4-1. 사각지대 '계산' — 보이는 걸 검출하는 게 아니라
- **입체 점유 계산(Occupancy)**: 트럭 뒤 안 보이는 영역에 보행자가 있을 확률을 계산 (검출이 아니라 추론). 충돌 위험 0.68 · 보행자 확률 0.55 같은 값을 실시간 산출.
- Tesla식 인지 코어(입체 점유·위험 예측 AI·집단 학습·의도 예측)에 한국 전용 인지(차량 간 협력·정류장 보행자 보정)를 더함.

### 4-2. 자체 학습 위험 예측 AI
| 항목 | 값 |
|---|---|
| 정확도 AUC | **0.9403** (목표 0.85 초과) |
| 균형 정확도 F1 | 0.9412 |
| 추론 속도 | 1.04ms (실시간) |
| 모델 크기 | 278KB (폰에 탑재) |

> AI 활용 — **학습도구**(직접 학습한 모델) + **분석도구**(온디바이스 객체 인식). API 호출이 아니라 직접 학습.

### 4-3. 한국형 8대 위험 시나리오 (법령·판례·기여도까지 매핑)
트럭 가림 / 좌측 사각 이륜 / 신호 가림 / 우천 교차로 / 우회전 보행자 / 스쿨존 / 자전거 / 야간 보행자
— 각 시나리오에 도로교통법 조항·대법원 판례·정량 기여도를 매핑. 글로벌 솔루션엔 없는 한국 법체계 정합성.

### 4-4. 25종 공공데이터 융합 엔진 (해자의 핵심)
11개 기관 · 25종을 한 번의 응답으로 융합 (0.2초). v1에서 v11까지 직접 어댑터로 연결.
- 주관기관 융합: 한국도로공사(VDS·돌발) + 한국교통안전공단(DTG·V2X)
- 국내공공: 도로교통공단(신호·TAAS)·국토부(ITS·DSZ·스쿨존)·기상청·환경부·소방청·경찰청·서울시 등
- 글로벌 보조: USGS 지진·OpenStreetMap (인증키 불필요)

### 4-5. 운전자 클라이언트 (모바일 UI) — 실제 작동 현황 (정직 표기)
| 기능 | 상태 |
|---|---|
| 카메라 + 온디바이스 객체 인식 | ✅ 단말 작동 |
| 위험 점수 + 25 융합 데이터 표시 + 신호 가림 경고 | ✅ 단말 작동 |
| 경고 발화(햅틱·음성) · 차량 간 전파 · 익명 데이터 기여 | ✅ 단말 작동 |
| 사각지대 입체 계산(BEV) | ◐ 서버 작동 (단말 표시는 다음 단계) |

## 6. 사업 모델 (Business Model) — 데이터 플라이휠

세 고객이 분리된 사업이 아니라 하나의 순환을 만든다.

| 고객 | 무엇을 하나 | 그들의 ROI | 우리 수익 |
|---|---|---|---|
| **B2C** 운전자 | 앱 설치·거치 | 사고 예방 + 사고 시 8시나리오 증거 | 월 **4,900원** · 5만명 → **30억** |
| **B2B** 운수(50만대 DTG) | fleet 관제 + 위험운전 점수 | **사고율 30%↓ → 보험료·배상금 절감** | 차량당 월 **9,900원** → **59억** |
| **B2G** 지자체(226 시군구) | 사각지대 통계 정책 리포트 | **실측 기반** 도로안전 정책 | 연 **2,000만원** → **13.5억** |

```
운전자가 깔수록 → 익명 사각지대 데이터 축적 →
모델 정확↑(집단 학습) + 정책 통계 풍부 →
지자체가 신호·교차로 개선 → 도로 안전↑ → 더 많은 운전자 유입 ↺
```

> **데이터 매출의 본체 = B2G 사각지대 통계.** B2C·B2B가 데이터를 만들고, 그 데이터가 B2G 상품이 된다.

## 7. 진입 전략 (Go-to-Market)

**"지금 돈 되는 건 B2B, 시장 먹는 건 B2C, 해자는 B2G 데이터."**

1. **1단계 — B2B 운수 (즉시 매출).** DTG 의무 차량은 예산이 있고, **보험료 절감이라는 명확한 ROI**가 있다. 운수사·보험사 파일럿으로 레퍼런스 + 데이터 확보.
2. **2단계 — B2G 지자체.** B2B에서 모인 실주행 데이터로 위험 교차로 Top-N 리포트 제공 → 서울 사고다발 Top-10 우선 도입(연 84명 예방 효과)으로 공공 레퍼런스.
3. **3단계 — B2C 대중화.** 블랙박스 1,500만 대 교체 주기에 올라타 소프트웨어로 확산. 플라이휠 가속.
