### S2 · Problem (30초)
"한국 교통사고의 **45%가 교차로**에서, 보행자 사망의 **60% 이상이 65세 이상 고령**입니다.
2024년 한 해 교통사고 **207,535건 · 사망 2,581명 · 부상 290,400명** (TAAS 2024).
기존 ADAS 와 Tesla FSD 는 **자기 카메라가 본 것만** 인지합니다.
대형차 뒤에 가려진 보행자, 사각지대 이륜차 — 모두 '모름'으로 처리됩니다."

### S2b · 임팩트 정량 (45초) ⭐
"AuraView 가 도시 교차로에 도입되면 — 라이브 검증 가능한 정량 효과:

| 도입 | 사고 예방/년 | 사망 감소 | 부상 감소 |
|---|---|---|---|
| **Pilot 5%** | **1,694건** | **21명** | **2,370명** |
| 확산 25% | 8,470건 | 105명 | 11,852명 |
| 전국 100% | 33,880건 | 421명 | 47,408명 |

산출 근거 모두 공개 — `/impact` JSON 에 출처·가정·공식 노출.
TAAS 통계 × 도시교차로 비중 46% × AuraView 적용 시나리오 42% × `min(0.85, 0.25 × lead_time_s)`.
트레인드 모델 평균 lead time **3.38초** → 회피율 **84.5%**."

### S3 · Solution (60초)
"AuraView 는 보이지 않는 공간을 **확률로 채웁니다**.

3D Occupancy Network 로 BEV(조감도) 격자에 점유 확률을 추정하고,
End-to-End Risk Transformer 로 향후 5초 충돌 확률을 직접 출력하며,
Fleet Learning 으로 어려운 장면만 자동 수집해 매주 모델을 업데이트합니다.

여기까지가 Tesla AI Day 의 카피판이라면,
**진짜 차별화는 다음 3가지**입니다."

## Q&A 대비

**Q: 학습 데이터는?**
A: 합성 4 시나리오 (혼합/러시아워/야간/우천) 8000+2000 샘플 + Fleet 누적 데이터.
   `notebooks/train_risk_transformer_real.py` 한 번이면 누구나 재현. AUC 0.9403.

**Q: 실제 차량에 들어갈 수 있나?**
A: Flutter 앱이 폰 그대로 엣지 단말이 됩니다.
   향후 ros2 노드로 차량용 ECU 통합 가능. 현재는 PoC.

**Q: 가명결합 / 안심구역 절차?**
A: TAAS × VDS 결합키는 시군구·일자 bucket·ITS 표준 링크만 사용,
   k-익명성 5 이상만 반출. dsz_exports/sample_taas_vds_join_2024.json 참조.

**Q: V2V 통신 표준?**
A: 현재는 HTTP 풀 (시연용). 운영은 C-ITS WAVE / 5G-V2X 표준 위에 매핑 가능.
   메시지 포맷은 SAE J2735 BSM 호환 가능한 구조.

**Q: 평균 5.7초 선행 경고 — baseline 대비?**
A: 일반 ADAS 의 lead time 은 0.5~1초.
   AuraView 가 가려진 영역까지 확률로 모델링하므로 4~5배 빠른 감지.
