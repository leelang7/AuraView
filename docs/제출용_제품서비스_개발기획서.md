## □ 제안배경

### - 제품·서비스의 개발 배경

  o **개발 동기 — 일반 ADAS 의 구조적 한계**
  - TAAS 2024 통계 기준 연 사망 **2,581명** / 부상 **290,400명**. 도시 교차로 (전체 사고 46%) 에서 트럭·버스에 가려진 신호등·보행자 사고가 22% 차지.
  - 일반 ADAS 의 선행 경고 시간은 **0.5~1초** (시속 60km/h 에서 회피 거리 8~16m) — 회피 성공률 25% 미만.
  - 단일 차량 시점만 활용 → 사각지대·occlusion 한계 본질적 해결 불가.

  o **국내외 시장 문제점**
  - Tesla FSD 등 글로벌 솔루션은 **한국 8 시나리오** (스쿨존·민식이법, 우회전 보행, 마주오는 차로, 119 골든타임 등) 미반영. 자율주행 등급 표시상 우수해도 한국 도로교통법 27·25·12조 적용 시 책임 회피 불가.
  - 한국이 보유한 **공공 인프라 데이터 25종** (도로공사 VDS·돌발·TAAS·KMA·119·KOTSA DTG·DSZ 등) 과 실시간 융합한 차량용 솔루션 부재.

### - 아이템의 필요성

  o **국토교통부 보유 데이터의 사회 환원 부족**
  - 데이터안심구역(DSZ) 의 가명결합 기반 사고분석 결과가 정책 보고서로만 머물고, 운전자가 실시간 활용할 수 있는 형태로 환원 안 됨.
  - 본 아이템은 DSZ 결합 결과를 **위험 교차로 Top-N 우선순위** 로 변환해 일반 운전자·지자체·운수업체에 환원.

  o **민식이법 시행 이후 운전자 부담 증가 대응**
  - 스쿨존 12조 위반 시 형사 처벌 강화 → 운전자 회피 정보 필요성 급증. AuraView 는 vworld 어린이보호구역 GIS + 통학로 GIS + KMA 결빙 데이터 융합으로 등하교 시간대 자동 위험 가중 표시.

## □ 세부내용

### - 아이템의 개발 및 사업화 전략

  o **제품 개요 — 블랙박스 1대 + 25종 공공데이터 융합 + 3.38초 선행 경고**
  - **카메라**: 일반 스마트폰/블랙박스 후면 카메라 (특수 H/W 불필요). Galaxy Z Fold 3 검증.
  - **AI 엔진**: 자체 학습 Risk Transformer (PyTorch · AUC 0.9403, F1 0.9412, p99 1.04ms · 67,970 params · 278KB on-device).
  - **공공데이터 융합**: 25종 (국내공공 23 + 보조 2) 실시간 호출 → `fusion.v11-2026.05.25-25src` 단일 JSON 결합.
  - **알림**: 햅틱 3-burst + 음성 안내 + V2V 광역 broadcast (heading 130°+).

  o **필요한 개인·공공 데이터 및 보유기관, 확보 방안**

  - 보조 2종 (USGS·OSM) 은 no-key 라이브 fallback 으로 12/25 source 가 키 없이도 실시간 동작.

  o **구현 기술·서비스 방법**
  - **백엔드** (FastAPI · Python 3.11): 149+ 엔드포인트, 융합 응답 p50 180ms, Docker 한 줄 가동.
  - **모바일** (Flutter 3.x · Dart): 카메라 frame stream → 위치/속도 게이트 → 익명 위험 이벤트 업로드.
  - **추론**: 단말 ML Kit (객체 검출) + 서버 Risk Transformer (위험 점수 0~1). 추론 지연 p99 1.04ms.
  - **융합 가중치 (v11)**: speed 0.13 + DTG 0.06 + 스쿨존 0.08 + 119 심각도 0.05 + 노면 0.06 + 보행자 0.05 + 단속존 0.04 + 횡단보도 0.05 + 50m 접근 × 1.10 + 지진 0.02 + 철도건널목 0.03~0.10.

  o **기존 유사 제품과의 차별점 — 한국 특화 5종 (Tesla 가 다루지 못함)**

| 카테고리 | Tesla FSD | AuraView |
|---|---|---|
| 차량 간 협업 인지 | 자기 시점만 | **V2V Cross-Vehicle** (heading 130°+ 가중 0.95) |
| 정류장 prior | generic 보행자 | **Bus-Aware** (dwelling/passing → +0.55 boost) |
| 마주오는 차로 | 단방향 | **Bidirectional Lane** + VDS 비대칭 |
| 공공 신호 결합 | vision only | **신호 API + ITS** 직접 호출 |
| 정책 환원 | Tesla 내부 데이터 | **위험 Top-N 자동 리포트 + DSZ 결합** |

  o **개발 제품만의 경쟁력 확보 방안**
  - **데이터 깊이**: 글로벌 솔루션이 자체 fleet 만 학습하는 반면, 한국 공공 인프라 25종 + 사용자 fleet 결합으로 cold-start 우위.
  - **법적 적합성**: 모든 시나리오에 도로교통법 조항 + 대법원 판례 매핑 (`/policy/laws`) — 정책 의사결정자가 즉시 신뢰 가능.
  - **오픈 검증**: MIT 라이센스 GitHub 공개 + 119/119 pytest PASS + 단일 URL 자가 진단 `/impact/submission-ready` (9 게이트 자동 검증).
  - **DSZ 완전 자동화**: 반입→결합→반출 전 과정 SHA-256 해시 검증 + 감사 로그 자동 생성 (`/dsz/pipeline-report`).

  o **UI/UX 서비스 예상 이미지**
  - 화면 상단: 실시간 카메라 + 검출 객체 cyan bounding box 오버레이.
  - 화면 하단: 위험 점수 게이지 (적/주의/안전 3단) + 4축 라이브 인디케이터 (entropy·motion·voxel·검출 카운트).
  - 위험 발화 시: 햅틱 3-burst + 음성 "전방 신호 가림, 즉시 정지" + V2V broadcast (반경 200m 차량).
  - 운영자 대시보드: 위험 교차로 Top-N 히트맵 + 정책 PDF 자동 생성 (3-page A4).

## □ 아이템의 실효성

### - 제품·서비스의 핵심 고객, 국내외 시장규모, 고객 편의 효과

  o **핵심 고객 3 segment**
  - **B2C — 일반 운전자**: 국내 블랙박스 보급 약 **1,500만 대** (보급률 90%+). 무료 앱 + 익명 데이터 기여 (Tesla shadow mode 모델).
  - **B2B — 영업용 운수업체**: 국내 사업용 차량 약 **50만 대** (택시·버스·화물). KOTSA DTG 의무 장착 대상 — 보험료 할인·운행 위험 모니터링 SaaS.
  - **B2G — 지자체·국토부**: 17개 시·도 + 226개 시·군·구. 위험 교차로 우선순위 정책 리포트 (월/분기).

  o **국내외 시장규모**
  - 국내 ADAS·블랙박스 시장: **연 1.2조원** (2024, 한국자동차연구원). 연 7.2% 성장.
  - 국내 V2X 시장: 2030년 **3,800억원** 예상 (정부 미래차 산업육성 계획).
  - 해외 잠재: 동남아·인도 등 한국형 도로 인프라 (좁은 골목·이륜차·보행자) 유사 신흥 시장.

  o **고객 편의 효과**
  - 운전자: 평균 3.38초 선행 경고 → 회피 성공률 **25% → 84.5%** 향상.
  - 운수업체: DTG 위험운전 패턴 자동 식별 → 사고율 평균 **30% 감소** (KOTSA 통계 가정).
  - 지자체: 위험 교차로 데이터 기반 신호 주기 조정·CCTV 우선 설치 의사결정 데이터 확보.

### - 개발된 제품의 매출 가능성 및 수익구조

  o **수익 모델**
  - **B2C Free + Premium**: 무료 (광고 X, 익명 데이터 기여) + Premium 월 4,900원 (V2V 광역 알림·HUD 미러링).
  - **B2B SaaS**: 운수업체 차량당 월 9,900원 (DTG·119 골든타임 라우팅). 50만대 × 10% 보급 시 연 **59억원**.
  - **B2G 정책 리포트**: 지자체당 연 2,000만원 × 226 시·군·구 × 30% 보급 시 연 **13.5억원**.

  o **3 년 매출 추정**: 1년차 5억 / 2년차 20억 / 3년차 70억.

### - 서비스의 확장 계획

  o **마이데이터 결합**: 사용자 동의 기반 운전 행태 데이터 → 보험사 (보험료 할인) · 정비소 (차량 진단) 연동.
  o **자율주행 V2X 데이터셋**: 익명 충돌 직전 frame 모음 → 국토부 자율주행 데이터허브 (av-hub) 기여 (현 직접 융합 중).
  o **해외 진출**: 일본·태국·베트남 (한국형 도시 도로 환경) 진출 — 현지 공공데이터 어댑터만 교체.
